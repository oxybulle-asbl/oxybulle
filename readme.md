# Oxybulle — website

Source code of [www.oxybulle.org](https://www.oxybulle.org), the website of Oxybulle asbl, a Belgian non-profit that offers a breath of fresh air to children and teenagers in the province of Namur who cannot grow up with their families.

Static site built with [Hugo](https://gohugo.io), based on the [Hugoplate](https://github.com/zeon-studio/hugoplate) theme (Tailwind CSS v4). Content is written in Markdown, in French.
